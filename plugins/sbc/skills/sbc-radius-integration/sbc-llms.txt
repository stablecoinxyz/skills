# SBC Documentation

> Complete documentation for SBC (Stable Coin) integration, account abstraction, and developer tools

## Docs

- [What SBC Offers](/what-sbc-offers): SBC (Stable Coin Inc) provides a complete account abstraction platform for building gasless blockchain applications. Our managed infrastructure handles the complexity of ERC-4337, so you can focus on building great user experiences.
- [SBC AppKit](/account-abstraction/app-kit): The SBC AppKit is a comprehensive SDK designed to simplify the integration of account abstraction features into your applications. It provides both a core TypeScript SDK and React components for seamless integration.
- [Account Abstraction Architecture](/account-abstraction/architecture): This page illustrates the transaction flow for SBC's Account Abstraction implementation, covering both ERC-4337 for gasless transactions and EIP-7702 for atomic multi-step operations.
- [Create SBC App](/account-abstraction/create-sbc-app): The fastest way to start building with SBC Account Abstraction. Instantly scaffold a feature-rich, gasless smart account app with a single command.
- [Direct Integration of SBC Paymaster and Bundler](/account-abstraction/direct-integration): For developers who prefer direct integration without using the SBC AppKit, you can interact directly with our Account Abstraction API endpoints. This approach gives you complete control over UserOperation creation and submission while leveraging SBC's custom paymaster and bundler infrastructure.
- [ERC-4337 Integration with SBC](/account-abstraction/erc4337-overview): [ERC-4337](https://eips.ethereum.org/EIPS/eip-4337) is the Account Abstraction standard for Ethereum that enables smart contract wallets to function like EOAs (Externally Owned Accounts) without requiring changes to the Ethereum protocol. This standard introduces several key components:
- [Account Abstraction Overview](/account-abstraction/overview): Account Abstraction (ERC-4337) is a standard that allows smart contract wallets to act like regular Ethereum accounts, enabling transactions to be processed through a central EntryPoint contract rather than directly by the network.
- [Supported Smart Account Implementations](/account-abstraction/smart-account-support): SBC supports a variety of smart account implementations for Account Abstraction, compatible with both ERC-4337 (EntryPoint v0.7) and upcoming EIP-7702 features for atomic transactions. These implementations enable enhanced functionalities such as gasless transactions, multi-signature security, and batched operations, providing flexibility for developers building on SBC's infrastructure.
- [Reward Distribution](/activity-rewards/distribution): Reward Distribution is a pivotal aspect of Stable Coin Inc's (SBC) strategy to incentivize user engagement and adoption of our stablecoin solutions. By allocating rewards based on tracked on-chain activity, SBC encourages users to interact with our ecosystem, fostering a vibrant community of developers and end-users.
- [Activity and Rewards Overview](/activity-rewards/overview): Stable Coin Inc (SBC) is committed to fostering engagement and incentivizing user activity within the blockchain ecosystem. Our Activity and Rewards initiative focuses on tracking on-chain interactions and distributing rewards to users based on their participation. This system is designed to encourage adoption of SBC tokens and enhance user interaction with our stablecoin solutions.
- [Activity Tracking](/activity-rewards/tracking): Activity Tracking is a core component of Stable Coin Inc's (SBC) strategy to incentivize and understand user engagement within the blockchain ecosystem. By monitoring on-chain interactions involving SBC tokens, we can gather valuable data to inform reward distribution and enhance our stablecoin solutions.
- [EIP-7702 Tools](/advanced/eip7702): This page provides an overview of SBC's upcoming EIP-7702 integration and tools.
- [LayerZero Integration](/advanced/layerzero): SBC is now integrated with LayerZero's interoperability infrastructure to enable seamless transfers between blockchains. This integration lets users easily move SBC between supported blockchain networks through a native mint and burn process.
- [Canton Network](/canton/overview): Canton is a privacy-preserving interoperability protocol for financial networks. SBC stablecoin is available on Canton, built on the CIP-56 token standard.
- [Privy Authentication](/integrations-demos/privy): Stable Coin Inc (SBC) has developed a demo integration with [Privy](https://www.privy.io/), a leading platform for user authentication and identity management in Web3. This integration simplifies the onboarding process for users, allowing them to interact with SBC-powered applications using familiar authentication methods like email, social logins, or phone numbers, while still benefiting from blockchain security and gasless transactions.
- [Radius Configuration Reference](/radius/configuration): Complete reference for configuring Radius in your SBC application.
- [Getting Started on Radius](/radius/getting-started): Build your first gasless application on Radius in under 5 minutes.
- [Radius Network](/radius/overview): [Radius](https://docs.radiustech.xyz/) is a high-performance, EVM-compatible settlement engine built for the machine-to-machine economy. It offers sub-second finality, stablecoin-native transactions (RUSD), and extremely low fees (~$0.000093 per transfer) — making micropayments and real-time API metering economically viable.
- [Zero Gas Mass Payment with SBC](/use-cases/mass-payment): This guide demonstrates how to implement gasless mass payments using SBC's custom paymaster and bundler. With this functionality, you can send SBC tokens to multiple recipients in a single transaction without paying gas fees.
- [Gasless NFT Minting](/use-cases/nft-minting): This guide demonstrates how to mint NFTs without paying gas fees using SBC's custom paymaster and bundler. This approach enables gasless NFT minting experiences for your users on Base and Base Sepolia networks.
- [Gasless USDC-SBC Swap](/use-cases/swap): This guide demonstrates how to implement a gasless swap between USDC and SBC tokens using SBC's custom paymaster and bundler. Users can swap tokens without needing ETH for gas fees.
- [x402 facilitator](/x402/facilitator): the sbc facilitator is a hosted service that verifies and settles x402 payments. it never holds funds — it receives a signed authorization from the payer and executes the on-chain transfer atomically.
- [x402 Payments](/x402/overview): Gate any HTTP endpoint behind a stablecoin payment. Payers sign off-chain — no gas fees on EVM, no pre-approval required. Your server middleware handles verification and settlement in one call.
