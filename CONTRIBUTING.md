# Contributing to skills

Thank you for your interest in contributing to this project!

## How to Contribute

Please open a GitHub issue or pull request. By submitting a contribution, you agree to follow the project's guidelines.

## Reporting Issues

Please open a GitHub issue for bug reports, feature requests, or questions.

## Security Vulnerabilities

Please do **not** file public GitHub issues for security vulnerabilities.
Report them privately — see [SECURITY.md](SECURITY.md) for instructions.

## Code of Conduct

Please be respectful and constructive in all interactions.
